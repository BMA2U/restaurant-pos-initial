# Restaurant POS System (SmartPOS)

## Overview
SmartPOS is an initial version of a **Point of Sale (POS)** system designed for restaurants.  
It allows restaurant owners and staff to manage essential operations such as users, options, and system settings through a simple Windows Forms interface.

---

## Features
- Manage restaurant information (name, phone, address, printer, etc.)
- User management (username, password, role, contact info)
- SQL Server database connection using `SqlDataAdapter` and `DataTable`
- Image handling (convert between image and byte data)
- Simple navigation and data editing (Next, Previous, First, Last)
- Automatic save and update operations

---

## Technology Stack
- **Language:** C# (.NET Framework / Windows Forms)
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio
- **Version Control:** Git + GitHub
